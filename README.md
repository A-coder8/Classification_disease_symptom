🧠 Disease Classification with Machine Learning

A Machine Learning classification project that predicts a possible disease based on a set of symptoms.

📌 About the Project

In this project, I built a Classification model that receives several symptoms as input and predicts the corresponding disease.

The dataset contains multiple symptom features and a target column representing the disease/class.

This project was created as part of my journey to learn and practice Machine Learning and Supervised Learning.

🛠️ Technologies & Libraries

- 🐍 Python
- 🧮 NumPy
- 🐼 Pandas
- 🤖 Scikit-learn

📂 Dataset

The dataset contains:

- Multiple symptom features
- A target column representing the disease
- Numerical/encoded feature values used by the Machine Learning model

Before training, the data was prepared and processed so that it could be used by the classification algorithm.

⚙️ Machine Learning Workflow

The general workflow of this project:

1. Load the dataset
2. Explore the data using Pandas
3. Clean and prepare the dataset
4. Separate features ("X") and target ("y")
5. Split the data into training and testing sets
6. Train the classification model
7. Make predictions
8. Evaluate the model
